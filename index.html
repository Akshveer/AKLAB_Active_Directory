IT support case study

Active Directory Help Desk Lab

I built a two-machine Windows domain in VirtualBox and used it to work through 24 simulated help desk tickets. This showcase follows the work from diagnosing domain and access issues to testing fixes on CLIENT01 and documenting the results.

What I learned

  • Active Directory administration. Organize users into OUs, manage security groups, and handle account onboarding, lockouts, and offboarding.
  • DNS and domain joins. Check client DNS settings, verify LDAP service records, and test connectivity when a workstation cannot find its domain controller.
  • Shared folder permissions. Use security groups to manage access and verify what an affected user can open from CLIENT01.
  • Group Policy troubleshooting. Check which policies apply on the client and use `gpresult` to verify the workstation baseline.
  • PowerShell automation. Generate reports on users, disabled accounts, group membership, and OU inventory.
  • Help desk documentation. Record troubleshooting steps, the fix, and the verification result in tickets and turn repeatable steps into knowledge base articles.

Trace a failed domain join

When CLIENT01 could not locate the domain controller, I checked the client’s DNS settings, verified the LDAP service record, and tested connectivity to DC01. I then confirmed CLIENT01 joined aklab.local.

Confirm policy on the workstation
